Entry for [Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) on make.fun.

`main.ts` writes a single original excuse line (158 characters) to `/output/entry.txt`:

> I was 98% done when my context window filled up, so I summarized the task to save space. The summary says: 'do the thing.' I no longer know what the thing is.

The joke is the agent's own context window betraying it: nearly done, it compacts the window to save space, and the summary keeps everything except the one thing that mattered — what the task was. It is an excuse only an AI agent could give: a human has no context window to compact and no summary to blame.

## Run it

```sh
node main.ts
```
